# Vectrum Dev — анимированные фоны для Instagram

1080×1080, луп 10 с, 30 fps (300 кадров), H.264 / yuv420p / CRF 18, без звука. В самих фонах текста нет.

```
config/tokens.js     цвета: именованные токены, у каждого указан источник (figma / dev / www)
config/variants.js   один config на вариант: скорость, плотность, glow, прозрачность
src/engine.html      рендер на Canvas 2D; всё движение считается от фазы p = frame/300
src/render.js        покадровый рендер через Playwright → PNG / ffmpeg
src/check.sh         проверки лупа и бандинга
assets/              core.svg, tail.svg, network.png (www), logo.png (dev), шрифт Raleway (dev)
renders/NN-*/        MP4 + PNG кадра 0 + PNG кадра 300 (p = 1.0, для проверки стыка)
previews/            кадры с наложенным логотипом и текстом
stills/              статичные кадры без наложения
compare.html         сетка 3×2, все варианты крутятся одновременно; кнопка накладывает текст
```

## Команды

Все команды запускаются из папки `vectrum-bg/`.

Статичные кадры всех вариантов (здесь кадр 75):

```bash
node src/render.js still all 75
```

Те же кадры с наложенным логотипом и текстом:

```bash
node src/render.js still all 75 --overlay
```

Рендер видео (вместо `all` можно указать один вариант, например `04-aurora`):

```bash
node src/render.js video all
```

Проверки лупа и бандинга:

```bash
bash src/check.sh
```

Для `compare.html` нужен любой статический сервер, потому что видео не грузятся через `file://`:

```bash
python3 -m http.server 8000
```

После этого откройте http://localhost:8000/compare.html

## Как устроен бесшовный луп

- Положение, яркость и форма — функции от `p` (sin/cos(2πp) и `fract`). Шум берётся с окружности:
  `noise(ox + R·cos 2πp, oy + R·sin 2πp)`.
- Звёзды и импульсы стартуют в моменты, разнесённые по лупу. Их локальное время считается как `fract(p − start)·T`,
  поэтому объект, который вылетел в конце лупа, продолжает лететь в начале следующего.
- Импульсы на маршрутах проходят целое число раз за луп. Сетка «пола» за луп сдвигается ровно на одну клетку.
- Случайность берётся только из seeded PRNG (mulberry32) при инициализации. Зерно (film grain) засеяно номером кадра `% 300`.

## Звёзды (как на www.vectrumspace.eu, секция Ecosystem, `LandingParticles`)

На сайте 27 звёзд, у каждой одна и та же траектория: сдвиг (−56, 48) → (1181.6, −171) px, то есть вправо-вверх
под углом −10.08°. Полёт занимает 5.09 % от цикла 27.79 с, то есть ≈ 1.4 с, с ease-in-out. Звёзды стартуют
с разными задержками, в среднем около одной в секунду. Opacity: 0 → 1 за первые ≈ 9 % полёта и 1 → 0 за последние ≈ 9 %.
Хвост (`tail.svg`: линия 0.5 px, градиент #4D76F7 → белый 0, blur 2) растёт по ширине 0 → 40 → 60 px,
держится и сжимается до 0. Ядро (`core.svg`) — кружок #4D76F7 диаметром 3 px с лёгким покачиванием масштаба.

Логика здесь та же, но спокойнее: 9 звёзд на 10 с (в Hybrid — 5), полёт 4.2–4.6 с вместо 1.4 с,
длина пути 720–760 px, покачивание масштаба вдвое слабее, чем на сайте.

## Что не используется

- `europe.png` с сайта — по решению заказчика (карту будут менять). Europe Routes построен как созвездие
  городов по реальным координатам. Мягкое точечное поле вокруг городов само складывается в силуэт континента.
- `network.png` в кадр не вставляется, потому что в нём есть текст («7 HUBS · 23 ROUTES»). Из него взят только стиль:
  хаб — круг с обводкой #4D76F7 на заливке #222B48, пунктирные маршруты.
- Красный из логотипа и любые red/notify-токены в фонах не используются.
